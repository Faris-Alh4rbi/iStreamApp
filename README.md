# iStream App – Task 5.1

An Android video playlist app 

## Features
- Sign up and login with credentials stored in a local database
- Paste a YouTube URL and play it inside the app
- Add videos to your personal playlist
- Each user has their own separate playlist
- Tap any saved URL to play it instantly
- Logout button on home and playlist screens

## Built With
- Java
- Android Studio
- Room Database (users and playlists)
- WebView with YouTube iFrame embed

## How to Run
1. Clone or download this repository
2. Open in Android Studio
3. Run on an emulator
